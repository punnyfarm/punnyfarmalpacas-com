# AGENTS Instructions for Punny Farm Website

## Scope

These instructions apply to all files in this repository unless a deeper `AGENTS.md` overrides them.

## Website Voice and Content

When editing content, keep the brand voice:

- Fun, happy, and lighthearted
- Pun-inspired (use tasteful puns, avoid overloading text)
- Family-style and welcoming
- Animal-centered (alpacas, dogs, and cats)

The website should make it clear that:

1. Punny Farm is an enjoyable farm destination
2. Guests can interact with or visit the animals respectfully
3. There is an Airbnb on the property for stays

## Copy Style

- Write in plain, friendly English
- Keep text concise and easy to scan
- Avoid sarcasm or edgy humor
- Keep tone appropriate for all ages

## Visual Style

- Favor bright, cheerful styling
- Prioritize readability and accessibility
- Keep layouts simple and mobile-friendly

## Maintenance

- Update README when major purpose/content changes occur
- Keep this AGENTS file aligned with any future brand changes
